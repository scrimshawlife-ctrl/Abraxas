# Plan: Four New Engines for Abraxas — Chronos, Resonance, Oracle, Aether

**Goal**: Spec and implement four new independent reasoning engines (Chronos, Resonance, Oracle, Aether) as separate repositories with their own specs, then integrate them into the Abraxas evidence arbitration kernel via the EvidenceProvider interface.

---

## Current Context / Assumptions

- **Abraxas** (main repo: `scrimshawlife-ctrl/Abraxas`) contains the evidence arbitration kernel:
  - `abraxas/evidence/contract.py` — EvidenceEnvelope, EvidenceType, Decision enums
  - `abraxas/evidence/provider.py` — EvidenceProvider interface, ProviderRegistry
  - `abraxas/evidence/arbiter/arbiter.py` — EvidenceArbiter, DefaultArbitrationPolicy
  - `abraxas/evidence/verifiers/` — 4 verifiers (Relational, Lexical, Sign, Latent)
  - `abraxas/governance/production.py` — ProductionOrchestrator, 6-gate governance
- **5 engines already integrated**: Athanor, Hyperlex, Semion, Noesis, Trutina
- **Each new engine MUST be its own repository** with:
  - Independent git history
  - Own SPEC.md, README.md, pyproject.toml
  - Own test suite
  - Own CI/CD
  - Publishes a Python package (or provides an adapter) that Abraxas consumes
- **Abraxas consumes engines via the EvidenceProvider interface** — engines do not import Abraxas; Abraxas imports engine adapters
- **Wire format**: Engine → EvidenceEnvelope → Abraxas Arbiter → DecisionRecord

---

## Architecture / Proposed Approach

Each engine follows the same pattern:
1. **New repo** created under `scrimshawlife-ctrl/<engine-name>`
2. **SPEC.md** defines the engine's reasoning domain, input/output contracts, and verification criteria
3. **Core implementation** in `src/<engine_name>/` with its own internal architecture
4. **Abraxas adapter** in `src/<engine_name>/compat/abraxas/` that implements `EvidenceProvider`
5. **Engine publishes to PyPI** (or provides local editable install) — Abraxas installs as dependency
6. **Abraxas registers engine** via `ProviderRegistry.register()` at startup

Integration is **one-way**: Engine → Adapter → Abraxas. No circular deps.

## Risks, Tradeoffs, Open Questions

### Risks
| Risk | Mitigation |
|------|------------|
| Circular dependency (engine imports Abraxas) | Enforce one-way: engine adapter only uses Abraxas contract types; Abraxas never imports engine core |
| Version skew (engine updates break Abraxas) | Pin engine versions in Abraxas `pyproject.toml`; use semantic versioning; test matrix in CI |
| 9-engine latency | Parallelize evidence collection in `ProductionOrchestrator.run_pipeline()` with `ThreadPoolExecutor` |
| JEV fallback costs | Cache JEV classifications; add cost tracking in governance "Rent" gate |

### Tradeoffs
- **Separate repos** = more overhead but true isolation, independent versioning, team autonomy
- **Shared EvidenceType enum** = Abraxas owns the enum; engines must update Abraxas to add types (intentional — prevents type sprawl)
- **Adapter pattern** = slight boilerplate but clean separation of concerns

## Appendix A: Oracle Narrative Hallucination Guard — Design

### Threat Model
Oracle takes a `DecisionRecord` + `EvidenceEnvelope[]` and generates human-readable narrative. Risk: LLM introduces claims not grounded in source evidence.

### Guard Architecture (3-Layer)

#### Layer 1: Structured Grounding (Deterministic)
- **Input**: `DecisionRecord` + `EvidenceEnvelope[]`
- **Process**: Extract every factual claim from generated narrative using spaCy NER + custom pattern matching (confidence numbers, engine names, decision outcomes, provenance hashes).
- **Check**: Every extracted claim must have a **provenance pointer** to a specific `evidence_id` + `candidate_output` + field path.
- **Output**: `GroundingReport` with `{claim: provenance_pointer | "UNGROUNDED"}`.
- **Fail**: Any `UNGROUNDED` claim → narrative rejected, sent back for regeneration with constraint.

#### Layer 2: Semantic Consistency (Verifier)
- **Component**: `NarrativeVerifier` (new verifier in `abraxas/evidence/verifiers/narrative.py`)
- **Input**: `EvidenceEnvelope` with `evidence_type = NARRATIVE_SYNTHESIS`
- **Process**: 
  1. Parse narrative into structured claims (using same extractor as Layer 1)
  2. For each claim, retrieve source `EvidenceEnvelope` from `provenance.source_engines`
  3. Compute semantic entailment: does source evidence **support** the claim? (Use lightweight entailment model — e.g., `microsoft/deberta-v3-small-mnli` or JEV fallback)
  4. Score each claim: `support ∈ [0, 1]`
- **Threshold**: Mean support ≥ 0.85; no claim < 0.6
- **Output**: `{passed: bool, details: {claim_support_scores, mean_support, ungrounded_claims}}`

#### Layer 3: Falsifiability Markers (Contractual)
- **Contract Requirement** (in Oracle SPEC.md): Every narrative **must** include a `## Falsifiability Markers` section listing:
  - For each major claim: "This claim would be falsified if [observable condition] occurs."
  - Confidence intervals on all numeric predictions
  - Explicit "Unknown / Not Computed" for gaps
- **Validator**: Automated check that markers section exists and covers ≥ 80% of claims.
- **Purpose**: Forces model to expose uncertainty; makes hallucination visible.

### Implementation in Oracle Engine
```python
# src/oracle/narrative.py
class OracleEngine:
    def synthesize(self, decision_record, envelopes, audience="technical"):
        # 1. Generate draft narrative (LLM with strict prompt)
        draft = self._llm_generate(decision_record, envelopes, audience)
        
        # 2. Layer 1: Grounding check
        grounding = GroundingChecker.check(draft, decision_record, envelopes)
        if grounding.ungrounded_claims:
            draft = self._regenerate_with_constraints(draft, grounding.ungrounded_claims)
            grounding = GroundingChecker.check(draft, decision_record, envelopes)
            if grounding.ungrounded_claims:
                raise GroundingFailure(grounding.ungrounded_claims)
        
        # 3. Layer 2: Semantic consistency (deferred to Abraxas verifier)
        #    We attach grounding report to provenance for verifier to use
        
        # 4. Layer 3: Ensure falsifiability markers
        if not FalsifiabilityValidator.has_markers(draft, min_coverage=0.8):
            draft = self._add_falsifiability_markers(draft, decision_record)
        
        return NarrativeOutput(
            text=draft,
            grounding_report=grounding,
            falsifiability_markers=extract_markers(draft)
        )
```

### Abraxas `NarrativeVerifier` (Layer 2 Implementation)
```python
# abraxas/evidence/verifiers/narrative.py
class NarrativeVerifier:
    evidence_type = "NARRATIVE_SYNTHESIS"
    
    def __init__(self, min_mean_support: float = 0.85, min_claim_support: float = 0.6):
        self.min_mean_support = min_mean_support
        self.min_claim_support = min_claim_support
        self.entailment_model = self._load_entailment_model()  # or JEV fallback
    
    def verify(self, envelope: EvidenceEnvelope) -> Dict[str, Any]:
        narrative = envelope.candidate_outputs[0].answer
        grounding = envelope.provenance.get("grounding_report", {})
        source_engines = envelope.provenance.get("source_engines", [])
        
        claims = ClaimExtractor.extract(narrative)
        support_scores = []
        ungrounded = []
        
        for claim in claims:
            ptr = grounding.get(claim.text)
            if not ptr or ptr == "UNGROUNDED":
                ungrounded.append(claim.text)
                support_scores.append(0.0)
                continue
            
            # Retrieve source evidence
            source_env = self._fetch_envelope(ptr)
            if not source_env:
                ungrounded.append(claim.text)
                support_scores.append(0.0)
                continue
            
            # Entailment check
            premise = self._evidence_to_premise(source_env)
            hypothesis = claim.text
            support = self.entailment_model(premise, hypothesis)
            support_scores.append(support)
        
        mean_support = sum(support_scores) / len(support_scores) if support_scores else 0.0
        min_support = min(support_scores) if support_scores else 0.0
        
        passed = (
            mean_support >= self.min_mean_support and
            min_support >= self.min_claim_support and
            len(ungrounded) == 0
        )
        
        return {
            "passed": passed,
            "escalate": not passed,
            "details": {
                "mean_support": mean_support,
                "min_support": min_support,
                "claim_count": len(claims),
                "ungrounded_claims": ungrounded,
                "claim_scores": list(zip([c.text for c in claims], support_scores)),
            }
        }
```
